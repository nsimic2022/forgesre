# Code of Conduct

ForgeSRE is built by people who are on call for real systems. Treat each other the way you
would want to be treated at 3 a.m. during an outage.

## Expected

- Be respectful and patient, especially with newcomers and people writing in a second language.
- Discuss the code and the idea, not the person.
- Assume good intent; ask before you conclude.
- Accept that maintainers may say no to a change, and explain why when they do.

## Not accepted

- Harassment, insults, or discriminatory jokes and language.
- Personal attacks or threats.
- Publishing someone's private information, logs, hostnames or credentials without permission.
- Sustained disruption of issues, pull requests or discussions.

## Reporting

Report a problem privately to the maintainers through GitHub
(<https://github.com/nsimic2022/forgesre>, the maintainer's profile contact or a private
security advisory). Reports are handled confidentially. Maintainers may edit or remove
comments and block people who break these rules.

This applies in every project space: issues, pull requests, discussions and any chat run for
the project.
