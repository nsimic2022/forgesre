Email & reports

This page only sends mail. There is no inbox — ForgeSRE does not receive email. Outbox is every generated / sent / failed message this appliance stored. SMTP off keeps the row as generated (lab). Escalation mail on an incident is unchanged. Grafana lives on System Health.

YAML host: smtp.office365.com port 587 tls: true. Same SMTP_* secrets. Replies stay in Outlook.
