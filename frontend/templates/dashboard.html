First-hour walkthrough

After install, this is the shortest path to see how ForgeSRE works. Nothing here changes a real server.

  1. Open forge-demo-01. Owner, email, phone, and a closed HighCPU history row are already filled.
  2. Run the demo workflow (admin). A live HighCPU incident opens. Escalation generates mail to platform@forgesre.local (the asset owner), not a generic team inbox.
  3. Open the new incident → Escalation (generated notification log) → the asset page again to see similar-incident history (closed demo + this one).
