Platform backup {% with %}{% set tip %}Full-system archive for crash recovery or VM migration. Each run is a folder data/backups/backup_YYYYMMDDTHHMMSSZ/ (gitignored, directory mode 700) with one forgesre.tar.gz (mode 600) plus a short MANIFEST.txt. Import that tar — do not unpack it into loose files. Includes config/forgesre.yml, .env, secrets/secrets.env, a logical Postgres dump (users, incidents, playbooks, playrules, journal), compressed logs, monitoring/alerts.local.yml, and data/generated/. Not in the backup: container images, Prometheus/Loki/Grafana volumes, nested backups, optional mailbox mail. LLM GGUF weights are skipped unless you tick the checkbox (they are often multi-GB). Download requires this admin session — there is no unauthenticated URL.{% endset %}{% include "_info_tip.html" %}{% endwith %}

ForgeSRE CLI

There is no terminal in this browser. Use SSH, then ./forgesre or ./forgesre shell.

Every ./forgesre subcommand. Details on the VM: ./forgesre help <command>.

CommandWhat it does
Update and stack
updateBackup, render monitoring, refresh images, restart, doctor (use after git pull)
restartRestart running stack containers only (no git pull, install, render, or secrets)
render-monitoringRewrite Prometheus / Alertmanager / snmp.yml from templates, reload snmp_exporter
statusdocker compose ps
logsContainer logs (default: last 100 lines)
configPrint config/forgesre.yml
versionAppliance version from .env
secrets-checkCheck the session key and webhook token are not shipped defaults (Core refuses to start on them)
installGuided first-time install (new VM only — never on a live box)
Health and verification
doctorShort health lights (Core API, Core (container), Prometheus, …)
testFull appliance report (files, HTTP, login, APIs, email, logs)
verifyLive chain: exporter → prometheus → alertmanager → core
ping · probeICMP + exporter /metrics for inventory (probe is the same command)
Inventory and SNMP
assets · inventoryList inventory with # (inventory is the same command)
snmpsnmp_exporter health + SNMP HTTP SD targets
snmp-authsWrite per-asset SNMP auths (Custom community / v3) into snmp.yml, reload snmp_exporter
sdPrometheus HTTP SD (Linux / Windows) and SNMP HTTP SD
Incidents and RCA
incidentsShort colored board (red/yellow/green); INC-… for one row
history90-day incident history (filters; INC-… for mail/audit/notes)
jobsBackground RCA job queue
journalInternal console reports (JSON)
demoHighCPU first-hour path (owner mail, similar history)
demo-rcaFilesystem RCA demo gauge (read-only)
demo-resetLower demo CPU/disk gauges (stops the demo HighCPU fire)
Backup
backupOne folder per run under data/backups (tar.gz + MANIFEST)
restoreList backup folders (newest first); apply only with --yes after stopping Core
importAlias for restore (numbered picker; also: import backup)
remove backupDelete one backup folder (tar + MANIFEST); confirm with --yes
Optional services
fetch-llmDownload Qwen 14B GGUF (~9 GB, not in git) and start llama.cpp
mailboxOptional Postfix/Dovecot + Roundcube (off; Core SMTP unchanged)
tlsHow to put optional HTTPS (Caddy) in front of Core
CLI session and prompt
loginSign in as a ForgeSRE user (engineer / analyst / …)
logoutForget CLI cookie (falls back to install admin)
whoamiPrint the CLI session user
shellSame prompt as ./forgesre with no args
completionPrint a source line for ~/.bashrc so TAB works in your login bash
helpThis overview, or detailed help for one command
quit · exitLeave the forgesre> prompt (Ctrl-D also works)
