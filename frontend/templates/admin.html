Full-system archive for crash recovery or VM migration. Each run is a folder data/backups/backup_YYYYMMDDTHHMMSSZ/ (gitignored, directory mode 700) with one forgesre.tar.gz (mode 600) plus a short MANIFEST.txt. Import that tar — do not unpack it into loose files. Includes config/forgesre.yml, .env, secrets/secrets.env, a logical Postgres dump (users, incidents, playbooks, playrules, journal), compressed logs, monitoring/alerts.local.yml, and data/generated/.

Not in the backup: container images, Prometheus/Loki/Grafana volumes, nested backups, optional mailbox mail. LLM GGUF weights are skipped unless you tick the checkbox (they are often multi-GB). Download requires this admin session — there is no unauthenticated URL.

Import / restore

Import only stores a tar.gz under data/backups/backup_…/. Restore overwrites the live database (users, incidents, playbooks). It does not run unless you tick the box and type RESTORE. Preferred after a crash or when migrating: SSH, stop Core, ./forgesre restore (pick a number) or ./forgesre restore data/backups/backup_YYYYMMDDTHHMMSSZ --yes, then ./forgesre update.

ForgeSRE CLI

There is no terminal in this browser. Use SSH, then ./forgesre or ./forgesre shell.

CommandWhat it does
