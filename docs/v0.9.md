# ForgeSRE V0.9 — current appliance

**Status:** current product (`0.9.0`)  
**History:** [V0.1](v0.1.md) through [V0.8](v0.8.md) stay as release notes. This file is the slice you are running.  
**How it is built:** [architecture.md](architecture.md). **How you run it:** [operator-handbook.md](operator-handbook.md).

V0.9 is the same Compose appliance as V0.8, with the operator surfaces that landed after that note: device syslog, Rules, the per-asset Ladder, the Escalated count, and one Incidents list.

## What you use now

1. **Version 0.9.0** — sidebar `v0.9`, FastAPI `version`, `FORGESRE_VERSION` in `.env.example` (written by `./forgesre update` via render-monitoring), CLI `./forgesre version`.
2. **Syslog and Loki** — devices send syslog to Alloy on UDP/TCP **514**. Lines are labeled by hostname and sender IP and stored in Loki. Loki is **logs** for incident evidence. It is not the graph source and it does not open incidents. Demo Core logs stay on `forge-demo-01`.
3. **Rules** (`/playrules`) — match **alertname** after ingest and attach a Playbook plus the default ladder. They do not create Prometheus rules and they do not run the Playbook.
4. **Standard alarms** — per-asset mute (and a threshold note) for bundled Prometheus alerts. Mute skips **ingest** of that alert. It does not blank Host metrics.
5. **Custom alarms** — per-asset rule list. The first ON rule with the same alertname wins over the Rules page. OFF skips that rule on this host only.
6. **Ladder** — per-asset mail steps (L1–L4). Empty uses the Default ladder. Email only. Acknowledge stops the climb.
7. **Escalated** — incidents that have climbed stay status `ESCALATED`. The Dashboard Incidents tile counts them. JSON acknowledge does not clear that status.
8. **History** — there is no separate History page. `/history` redirects to **Incidents**, which lists every status.
9. **Host metrics** — Asset page, Dashboard (the one selected Recent incident), and the incident page chart Prometheus `query_range` (SD `job` + `instance`, or the SNMP target). The asset page is the last hour for that host, healthy or in problem. An incident chart runs from one hour before it started through now, or through the end if it is resolved, with a vertical line at When. Zabbix `trend.get` is only the fallback when Prometheus has no samples. **Not scraped.** / **No samples yet.** / **Steady.** No placeholder wave. Mute does not change the chart. Grafana is not embedded.

## Existing VM

```bash
git pull origin main
./forgesre update
./forgesre doctor
./forgesre version   # 0.9.0
```

Do not run `./install.sh` again.

## Not in V0.9

- Celery, a second Core replica, or extra uvicorn workers.
- Executing playbooks, or writing to NetBox or Zabbix.
- A Go / Kubernetes / Caddy rewrite. Those ideas are **not shipped**.
