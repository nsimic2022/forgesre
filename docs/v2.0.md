# ForgeSRE V2.0 — current appliance

**Status:** current product (`2.0.0`)
**Before:** [V0.9](v0.9.md) and older release notes. **How you use it:** the [guide](README.md#guide).

V2.0 is the same single-VM Compose appliance, with a new operator interface and the
features that make incidents shorter. Updating from V0.9 is the usual `git pull` and
`./forgesre update`; nothing has to be reinstalled.

## What is new

1. **New UI is home.** `/` opens the new interface (`/app`): NOC overview, Incidents,
   Inventory, Automation, Investigations, Reports and Settings, in a dark "Signal" style.
   Operators can do the daily work and the editing (assets, rules, filters, playbooks,
   escalation, on-call, maintenance) without leaving it.
2. **Wall screen (TV mode)** with the 12-hour **incident clock**.
3. **What changed before**: deploys, config pushes and tickets posted by CI/CD or GLPI,
   plus ForgeSRE's own audit log, shown on each incident.
4. **Dependency map** from LibreNMS LLDP/CDP, with parent-down suppression.
5. **Acknowledge from mail** with a scanner-safe one-click page.
6. **Postmortem draft** in Markdown, built only from recorded facts.
7. **Appliance checks**: TLS certificate expiry, backup age, heartbeats (`./forgesre checks`).
8. **SLOs and error budgets** (`./forgesre slo`).
9. **Chat notifications**: Slack, Microsoft Teams, Discord.
10. **Kubernetes, OpenShift, k3s** read-only cluster reader ([kubernetes.md](kubernetes.md)).
11. **Read-only MCP server** for AI clients, off by default ([mcp.md](mcp.md)).
12. **Documentation**: a six-chapter guide with screenshots.
13. **Inventory**: CSV import, 30-day capacity with days to full (`./forgesre capacity`), one
    inventory fed by GLPI, Zabbix, NetBox and LibreNMS with conflicts to review
    (Inventory › Sources, `./forgesre sources`), business services on assets.
14. **Printers are never probed on TCP 9100**, their raw print port.
15. **Incidents**: Send report by mail, Settings › Demo scenarios.
16. **ForgeAI**: the morning digest mail, skill tuning against confirmed causes with replays, and
    *Investigate with tools* (read-only tools, cited evidence) ([llm.md](llm.md)).
17. **SLO per business service.**
18. **Enterprise**: sign-in with LDAP / Active Directory and OIDC single sign-on
    ([sign-in.md](sign-in.md)), several web workers and an optional worker process, an offline
    bundle for appliances without internet ([offline.md](offline.md)), and a documented
    active / standby setup ([high-availability.md](high-availability.md)).

git pull origin main
