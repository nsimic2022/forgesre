# ForgeSRE V0.3 — RCA foundation

**Status:** implemented on top of V0.1/V0.2  
**Plan:** [`V03_IMPLEMENTATION_PLAN.md`](V03_IMPLEMENTATION_PLAN.md)

ForgeSRE owns the RCA abstraction. A local LLM is optional. Production RCA is ForgeRCA.

---

## Pipeline

```
Incident → evidence collection → RCA context → ForgeRCA
         → facts / anomalies / hypotheses → optional LLM wording
         → scored result → UI + audit
```

AI is read-only. Recommended actions are never executed.

---

## Operator path

V0.1 CPU demo is unchanged:

```bash
./forgesre demo
```

V0.3 filesystem RCA demo (demo gauge, does not fill a real disk):

```bash
./forgesre demo-rca
```

Then open the incident → **AI Investigation**. Analysts see facts and likely cause. Engineers see PromQL/LogQL on the same page.

---

## Confidence

ForgeSRE calculates confidence. The LLM’s number is ignored.

```
0.45 baseline
+ up to 0.20 for anomalies
+ up to 0.20 for supporting evidence
− up to 0.15 for contradicting evidence
+ 0.08 similar historical incident
− 0.20 overlapping maintenance
− 0.15 Prometheus or Loki unavailable
clamp [0.15, 0.95]
```

This is a simple operational score, not a validated reliability model. The UI says so.

---

## Engine

ForgeRCA (`ai.rca.engine: forgerca`). Config also has `ai.rca.window_minutes` (default 30).

---

## What V0.3 will not do

SSH, shell, Docker socket, playbook execution, Code Agent, Visual Agent graph engine, Data/Report agents as services.
